# Diep.io Tek Oyunculu V2

Bu repo, tarayıcı tabanlı tek oyunculu bir **Diep.io** oyununu içermektedir.

## Dosyalar

| Dosya | Açıklama |
|-------|----------|
| `index.html` | Oyunun tüm kaynak kodu (HTML + CSS + JavaScript) |
| `diep-tek-oyunculu-repo.zip` | `index.html` dosyasının sıkıştırılmış yedeği |

## Oyun Hakkında

`index.html` aşağıdaki özellikleri içerir:

- **Oyuncu hareketi**: `W`, `A`, `S`, `D` tuşları
- **Ateş etme**: Sol fare tuşu (mouse imlecine doğru ateş eder)
- **Düşmanlar**: Ekranın kenarlarından belirli aralıklarla spawn olur ve oyuncuya doğru ilerler
- **Seviye sistemi**: Düşman öldürerek XP kazan, belli bir XP'ye ulaşınca seviye atla
- **HUD**: Ekranın sol üst köşesinde mevcut seviye ve XP bilgisi gösterilir

## Nasıl Oynanır

`index.html` dosyasını herhangi bir web tarayıcısında açmanız yeterlidir.
